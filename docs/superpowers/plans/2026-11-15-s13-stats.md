## Structure et interfaces communes

`research/stats/types.rs` porte les seules entrées numériques partagées. Types
minimaux à stabiliser au lot 1 avant les consommateurs :

```rust
pub struct TradeRecord {
    pub row: usize, pub lot_id: u64, pub symbol: String,
    pub entry_ms: i64, pub exit_ms: i64,
    pub qty: f64, pub entry_price: f64, pub exit_price: f64,
    pub entry_fee: f64, pub exit_fee: f64,
    pub pnl_net: f64, pub r_multiple: Option<f64>, pub included: bool,
}
pub struct Window { pub start_ms: i64, pub end_ms: i64 }
pub struct MarkPoint {
    pub at_ms: i64, pub equity: f64, pub day_close: bool,
}
pub struct PricePoint { pub at_ms: i64, pub close: f64 }
pub struct CashPoint { pub at_ms: i64, pub cash: f64 }
pub enum StatsSizing { Research, Compounding }
pub struct StatsOptions {
    pub seed: u64, pub samples: u32, pub bootstrap_block: usize,
    pub correlation_threshold: f64,
}
```

Une ligne de trade se référence par `row` (ordinal immuable du CSV) et ses champs
symbol/lot/entrée/sortie : des sorties partielles peuvent partager les autres clés.
Toutes les mesures sérialisent des Options ; un statut complete/partial/unavailable
avec raisons expose les absences. Les types de résultats précis appartiennent au
module du calcul, réexportés par `stats/mod.rs`. Les signatures de base sont :

```rust
pub fn bootstrap(trades: &[TradeRecord], options: &StatsOptions)
    -> Result<BootstrapStats, StatsError>;
pub fn concentration(trades: &[TradeRecord])
    -> Result<ConcentrationStats, StatsError>;
// TradeClosure{row,at_ms} pointe le marquage après réalisation et est réexporté par MC.
pub fn monte_carlo(trades: &[TradeRecord], closures: &[TradeClosure],
    marks: &[MarkPoint], window: Window, capital: f64,
    sizing: StatsSizing, options: &StatsOptions)
    -> Result<MonteCarloStats, StatsError>;
```

Les fonctions régimes/benchmarks/clustering prennent tableaux explicites de prix,
marquage et rendements, jamais des chemins. Le lot 1 publie le contrat effectif
au pilote ; les noms et signatures du plan sont alignés avant raccordement.
